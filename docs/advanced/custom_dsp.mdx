## Overview

For effects and instruments that require **zero ring-buffer latency** or sample-by-sample feedback loops—such as state-variable filters, Moog ladder filters, wavefolders, sidechain effects, physical modeling, or hosting external C++/Rust/FAUST/Cmajor/VST DSP blocks—*flutter_soloud* provides two synchronous callback APIs:

1. **`createCustomSource` (`CustomAudioSource`)**: A custom `SoLoud::AudioSource` whose callback is invoked directly by the SoLoud mixer whenever it needs to render a block of audio samples.
2. **`filters.customFilter(int id)` (`CustomFilter`)**: A custom `SoLoud::Filter` that processes audio in-place inside any filter chain (**Global**, **Mixing Bus**, or **Single Sound**), supporting **up to 8 independent `CustomFilter` slots (`id: 0..7`) on the same scope** and **16 modulatable parameters** (`wet` + `p1`..`p15`).

Both mechanisms work across all 6 supported platforms:
- **Linux, macOS, Windows, Android, iOS**: Direct native function pointer invocation (`dart:ffi` `Pointer.fromFunction` or compiled C/C++/Rust symbol).
- **Web (Wasm / JavaScript)**: Zero-copy Emscripten `EM_ASM` / Wasm function table invocation inside the WebAudio AudioWorklet / ScriptProcessor context (`globalThis[jsCallbackName]`).

<Warning>
**Real-Time Audio Thread Rules:**
Because `CustomAudioSource` and `CustomFilter` callbacks execute **synchronously on the real-time audio thread**, your callback must **never**:
- Allocate heap memory (`new`, `malloc`, creating Dart `List`s or closures inside the loop)
- Acquire mutex locks (`std::mutex`)
- Perform file/network I/O or call `print()` / `debugPrint()`
- Perform async operations (`Future`, `Stream`)
</Warning>

## Multi-Instance `CustomFilter` (`filters.customFilter(id)`)

Unlike built-in filters (which allow one instance per `FilterType` on a given scope), `customFilter(int id)` lets you attach up to **8 independent custom DSP filters (`id` in `0..7`)** to the same Global, Bus, or Single-Sound scope.

### Automatic 3-Branch `wet` Bypass & Blending

Every `CustomFilter` includes `wet` (`param[0]`, range `0.0..1.0`, default `1.0`) plus 15 user-definable parameters (`p1`..`p15`, or `param(1)`..`param(15)`).

The C++ engine (`SoLoud::CustomFilterInstance::filter()`) automatically manages dry/wet mixing and CPU bypass:
1. **`wet <= 0.0` (Hard Bypass)**: The engine returns immediately without invoking your callback (**0% CPU cost**).
2. **`wet >= 1.0` (100% Wet, Zero-Copy)**: The engine passes `aBuffer` directly to your callback in-place with **zero memory copies**.
3. **`0.0 < wet < 1.0` (Automatic Blend)**: The engine snapshots the dry input into a pre-allocated scratch buffer, invokes your callback in-place, and blends `dry * (1.0 - wet) + processed * wet`.

<Info>
Because the engine handles `wet` (`param[0]`) automatically, your DSP callback should always write the **100% wet processed signal** into `buffer`.
</Info>

### Example: Chaining Two Custom Filters on the Global Mixer

```dart
import 'dart:ffi' as ffi;
import 'package:flutter/foundation.dart';
import 'package:flutter_soloud/flutter_soloud.dart';

/// Slot 0: Soft-Clipping Overdrive + Tremolo
void _overdriveDspCallback(
  ffi.Pointer<ffi.Float> buffer,
  int samples,
  int channels,
  double sampleRate,
  double time,
  ffi.Pointer<ffi.Float> params,
  int numParams,
  ffi.Pointer<ffi.Void> userData,
) {
  final drive = params[1]; // p1
  final total = samples * channels;
  for (var i = 0; i < total; i++) {
    final x = buffer[i] * drive;
    final x2 = x * x;
    // Fast rational tanh soft-clipper
    buffer[i] = (x * (27.0 + x2) / (27.0 + 9.0 * x2)).clamp(-1.0, 1.0);
  }
}

/// Slot 1: Bitcrusher & Sample-Rate Decimator
void _bitcrusherDspCallback(
  ffi.Pointer<ffi.Float> buffer,
  int samples,
  int channels,
  double sampleRate,
  double time,
  ffi.Pointer<ffi.Float> params,
  int numParams,
  ffi.Pointer<ffi.Void> userData,
) {
  final levels = params[1].clamp(2.0, 256.0); // p1
  final decimate = params[2].round().clamp(1, 32); // p2
  for (var c = 0; c < channels; c++) {
    final chOffset = c * samples;
    var held = 0.0;
    for (var i = 0; i < samples; i++) {
      if (i % decimate == 0) {
        final s = buffer[chOffset + i];
        held = (s * levels).roundToDouble() / levels;
      }
      buffer[chOffset + i] = held;
    }
  }
}

void setupCustomFilterChain() {
  final slot0 = SoLoud.instance.filters.customFilter(0);
  slot0.defineParam(1, name: 'Drive', min: 1.0, max: 10.0, def: 2.5);

  final slot1 = SoLoud.instance.filters.customFilter(1);
  slot1
    ..defineParam(1, name: 'QuantLevels', min: 2.0, max: 64.0, def: 16.0)
    ..defineParam(2, name: 'Decimate', min: 1.0, max: 24.0, def: 4.0);

  if (kIsWeb) {
    slot0.setCallback(jsCallbackName: 'myOverdriveFilter');
    slot1.setCallback(jsCallbackName: 'myBitcrusherFilter');
  } else {
    slot0.setCallback(
      nativeCallback: ffi.Pointer.fromFunction<NativeCustomFilterDspCallback>(
        _overdriveDspCallback,
      ),
    );
    slot1.setCallback(
      nativeCallback: ffi.Pointer.fromFunction<NativeCustomFilterDspCallback>(
        _bitcrusherDspCallback,
      ),
    );
  }

  // Activate both slots in series on the global output bus
  slot0.activate();
  slot1.activate();

  // Live parameter control, fading, and LFO oscillation work out of the box!
  slot0.p1.value = 4.0;
  slot0.p1.oscillateFilterParameter(
    from: 1.5,
    to: 7.0,
    time: const Duration(milliseconds: 1500),
  );

  // Set wet to 0.0 to hard-bypass slot 1 with zero CPU overhead
  slot1.wet.value = 0.0;
}
```

## Custom Audio Generator (`createCustomSource`)

`SoLoud.instance.createCustomSource(...)` creates a regular `AudioSource` backed by your synchronous generator callback. Because it is a full `AudioSource`, you can:
- Play multiple polyphonic instances (`play`, `play3d`, `playClocked`, `playScheduled`)
- Route it through Mixing Buses (`bus.play(customSource)`)
- Attach per-sound filters (`customSource.filters.echoFilter.activate()`, `customSource.filters.customFilter(0).activate()`)

### Example: Custom Audio Generator

```dart
import 'dart:ffi' as ffi;
import 'dart:math' as math;
import 'package:flutter/foundation.dart';
import 'package:flutter_soloud/flutter_soloud.dart';

double _oscPhase = 0;

int _customSynthCallback(
  ffi.Pointer<ffi.Float> buffer,
  int samplesToRead,
  int bufferSize,
  int channels,
  double sampleRate,
  ffi.Pointer<ffi.Void> userData,
) {
  final phaseInc = 2.0 * math.pi * 220.0 / sampleRate;
  for (var i = 0; i < samplesToRead; i++) {
    final s = math.sin(_oscPhase) * 0.35;
    _oscPhase += phaseInc;
    if (_oscPhase > 2.0 * math.pi) _oscPhase -= 2.0 * math.pi;

    // Planar layout: channel `c` starts at `c * bufferSize`
    for (var c = 0; c < channels; c++) {
      buffer[c * bufferSize + i] = s;
    }
  }
  return samplesToRead;
}

void playCustomGenerator() {
  final source = SoLoud.instance.createCustomSource(
    channels: Channels.stereo,
    sampleRate: 48000,
    hasEnded: false,
    jsAudioCallbackName: kIsWeb ? 'myCustomSynthGenerator' : null,
    nativeAudioCallback: kIsWeb
        ? null
        : ffi.Pointer.fromFunction<NativeCustomSourceAudioCallback>(
            _customSynthCallback,
            0,
          ),
  );

  final handle = SoLoud.instance.play(source);
}
```

<Info>
**Planar Buffer Layout:**
Inside both `NativeCustomSourceAudioCallback` and `NativeCustomFilterDspCallback`, SoLoud stores audio in **planar** format:
- In `NativeCustomFilterDspCallback`, channel `c` (`0 <= c < channels`) occupies `buffer[c * samples + i]`.
- In `NativeCustomSourceAudioCallback`, channel `c` occupies `buffer[c * bufferSize + i]` for `0 <= i < samplesToRead`.
</Info>

## Web Platform (`jsCallbackName`)

On the Web platform, `flutter_soloud` compiles the C++ engine to WebAssembly via Emscripten (`Module_soloud`). When you register a `jsCallbackName` on a `CustomFilter` or `CustomAudioSource`, the C++ engine invokes `globalThis[jsCallbackName]` directly inside the Wasm audio rendering loop using inlined `EM_ASM` macros:

```javascript
// In your web/index.html or via dart:js_interop:
globalThis.myOverdriveFilter = function(
  bufferPtr,
  samples,
  channels,
  sampleRate,
  time,
  paramsPtr,
  numParams,
  userDataPtr
) {
  const heap = Module_soloud.HEAPF32;
  const paramBase = paramsPtr >> 2;
  const drive = heap[paramBase + 1]; // p1
  const bufBase = bufferPtr >> 2;
  const total = samples * channels;

  for (let i = 0; i < total; i++) {
    const x = heap[bufBase + i] * drive;
    const x2 = x * x;
    heap[bufBase + i] = Math.max(-1.0, Math.min(1.0, (x * (27.0 + x2)) / (27.0 + 9.0 * x2)));
  }
};
```
