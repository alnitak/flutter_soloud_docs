## Overview

3D audio allows you to position sounds in 3D space, creating immersive audio experiences. The coordinate system is right-handed:

```text
          Y
          ^
          |
          |
          |
          --------> X
         /
        /
       Z
```

## Basic 3D Playback

Play a sound with 3D positioning:

```dart
final handle = SoLoud.instance.play3d(
  sound,
  10.0, // posX
  0.0,  // posY
  5.0,  // posZ
  velX: 0.0, // optional velocity
  velY: 0.0,
  velZ: 0.0,
  volume: 1.0,
  scale: 1.0,
  looping: false,
);
```

## Listener Control

Configure the audio listener (usually your game's camera or player):

```dart
// Set listener position
SoLoud.instance.set3dListenerPosition(0, 0, 0);

// Set listener orientation
SoLoud.instance.set3dListenerAt(0, 0, 1);  // looking forward
SoLoud.instance.set3dListenerUp(0, 1, 0);   // up vector

// Set listener velocity (for doppler effect)
SoLoud.instance.set3dListenerVelocity(0, 0, 0);

// Or set all parameters at once
SoLoud.instance.set3dListenerParameters(
  0, 0, 0, // position
  0, 0, 1, // looking direction
  0, 1, 0, // up vector
  0, 0, 0, // velocity
);
```

<Info>
All 3D methods throw `SoLoudNotInitializedException` before `init()`, and every position, velocity and 3D parameter throws an `ArgumentError` if it is NaN or infinite.
</Info>

## Sound Source Control

Control individual 3D sound sources:

```dart
// Update sound position
SoLoud.instance.set3dSourcePosition(handle, x, y, z);

// Set sound velocity
SoLoud.instance.set3dSourceVelocity(handle, velX, velY, velZ);

// Set both at once
SoLoud.instance.set3dSourceParameters(
  handle,
  posX, posY, posZ,
  velX, velY, velZ,
);
```

## Distance Attenuation

Configure how sounds fade with distance:

```dart
// Set minimum and maximum distances
SoLoud.instance.set3dSourceMinMaxDistance(
  handle,
  1.0,     // minimum distance
  1000.0,  // maximum distance
);

// Set attenuation model
SoLoud.instance.set3dSourceAttenuation(
  handle,
  2,    // LINEAR_DISTANCE model
  1.0,  // rolloff factor
);
```

By default a source uses `NO_ATTENUATION` with a rolloff factor of 1, and minimum and maximum distances of 1 and 1000000, so a 3D sound does not get quieter with distance until you set an attenuation model.

Available attenuation models:
- `0`: NO_ATTENUATION - No distance attenuation
- `1`: INVERSE_DISTANCE - 1/distance attenuation
- `2`: LINEAR_DISTANCE - Linear distance attenuation
- `3`: EXPONENTIAL_DISTANCE - Exponential distance attenuation

## Defaults of a Sound

The setters above act on one voice, through its handle, after `play3d` has created it. They have to be repeated after every `play3d`, and the voice can be heard for a moment without them.

To give every voice of a sound the same 3D settings, set them once on the `AudioSource`:

```dart
final torch = await SoLoud.instance.loadAsset('assets/torch.ogg');

SoLoud.instance.set3dDefaultAttenuation(torch, 2, 1);        // linear, rolloff 1
SoLoud.instance.set3dDefaultMinMaxDistance(torch, 1, 30);
SoLoud.instance.set3dDefaultDopplerFactor(torch, 1);

// Every torch gets quieter with distance, with no call on its handle.
SoLoud.instance.play3d(torch, x, y, z, looping: true);
```

A voice copies these values when it is created, so they hold from its first sample. This also works with `play3dClocked` and `play3dScheduled`, and while the automatic 3D update is disabled (see [Many Moving Sources](#many-moving-sources)).

| Method | Sets | Default |
| --- | --- | --- |
| `set3dDefaultAttenuation(sound, attenuationModel, attenuationRolloffFactor)` | Attenuation model and rolloff factor | `0` (no attenuation), `1` |
| `set3dDefaultMinMaxDistance(sound, minDistance, maxDistance)` | Minimum and maximum distance | `1`, `1000000` |
| `set3dDefaultDopplerFactor(sound, dopplerFactor)` | Doppler factor | `1` |

<Info>
The defaults apply to voices started after the call. Voices of that sound that are already playing keep their values, and a `set3dSource*` setter still changes a single voice. Nothing happens if the sound is not loaded.
</Info>

## Doppler Effect

Control the doppler effect strength:

```dart
// Set doppler factor (0 = disable, 1 = normal, >1 = exaggerated)
SoLoud.instance.set3dSourceDopplerFactor(handle, 1.0);

// Set speed of sound (affects doppler calculations)
SoLoud.instance.set3dSoundSpeed(343.0); // meters/second
```

## Many Moving Sources

By default every 3D setter (the `set3dListener*` and `set3dSource*` methods and `set3dSoundSpeed`) recomputes the panning, attenuation and doppler of all the 3D voices before it returns. A game that moves many sources calls these setters many times per frame, and each call is a full pass over the 3D voices.

Disable the automatic update, and apply everything once per frame with `update3dAudio()`:

```dart
// Once, after init().
SoLoud.instance.set3dAutoUpdate(false);

// Every frame.
void update(double dt) {
  SoLoud.instance.set3dListenerParameters(
    cam.x, cam.y, cam.z,
    cam.forwardX, cam.forwardY, cam.forwardZ,
    cam.upX, cam.upY, cam.upZ,
    cam.velX, cam.velY, cam.velZ,
  );
  for (final e in movingEmitters) {
    SoLoud.instance.set3dSourceParameters(
      e.handle, e.x, e.y, e.z, e.vx, e.vy, e.vz,
    );
  }
  // One pass for the listener and all the sources.
  SoLoud.instance.update3dAudio();
}
```

| Method | Description |
| --- | --- |
| `set3dAutoUpdate(bool enabled)` | `true` (default): every 3D setter applies its change at once. `false`: the setters only store their values. Passing `true` applies what was stored. |
| `get3dAutoUpdate()` | The current mode. |
| `update3dAudio()` | Applies the stored values to all the 3D voices in one pass. Needed only after `set3dAutoUpdate(false)`. |

<Warning>
With `set3dAutoUpdate(false)` nothing is heard of a setter until `update3dAudio()` is called: without it the sources and the listener seem frozen. `init()` restores the automatic update, so disable it again after every `init()`.
</Warning>

`play3d` and its variants place a new voice by themselves in both modes, using the values passed to the call, the listener values set so far and the [defaults of the sound](#defaults-of-a-sound). What is set on the handle of the voice afterwards waits for `update3dAudio()` like any other setter.

## Best Practices

- Keep coordinate scales consistent throughout your application
- Update listener and source positions every frame if moving
- Use appropriate attenuation models for your game/app scale
- Consider performance when using many 3D sound sources
- Set appropriate minimum/maximum distances for your scale
- Set the attenuation of a sound once with `set3dDefaultAttenuation` and `set3dDefaultMinMaxDistance` instead of repeating the handle setters after every `play3d`
- With many moving sources, use `set3dAutoUpdate(false)` and one `update3dAudio()` per frame
- Use doppler effects sparingly for better performance
